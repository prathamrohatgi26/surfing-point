# Surfing Point

Landing page for **Surfing Point**, Meerut — travel ticketing, insurance, digital signature (DSC), passport services and online works.

Built with Next.js (App Router), React and Tailwind CSS v4. Fully static, no backend.

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm start       # serve the production build
```

## Editing business details

Phone, email, WhatsApp number, address, map link, opening hours and the site URL all live in
`src/lib/site.js`. Change them there and every section, the metadata and the structured data update together.

The social share image is generated by `src/app/opengraph-image.js`.
